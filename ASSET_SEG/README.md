# 🎨 Panorama Segmentation Service

## 🚀 Overview

This service is responsible for analyzing a 360° panoramic image and decomposing it into semantic components for the Text2VR pipeline. Its main workflow is:
1.  Use a Vision-Language Model (**GPT-4V**) to automatically identify potential interactive assets within the panorama.
2.  Use **GroundingDINO** to locate these assets based on the generated text prompts.
3.  Use the **Segment Anything Model (SAM)** to generate precise, pixel-level masks for each located asset.
4.  Save the final masks for use in the next stage of the pipeline.

This service runs in a dedicated Docker environment with modern libraries (`transformers>=4.39.0`, etc.) to support the latest AI models, completely isolated from the `dreamscene360_service` environment.

---

## 🛠️ Standalone Usage for Development

All dependencies are managed by the `Dockerfile` in this directory, orchestrated by the main `docker-compose.yml` at the project root. To work on this service in isolation, use the following commands from the **root of the Text2VR repository**.

### 1. Build the Service Image
If you've made changes to this service's `Dockerfile` or `requirements.txt`, you must rebuild its image.
```bash
docker-compose build segmentation
```

## 2. Configure API Key
This service requires an OpenAI API key to automatically identify assets. Ensure it is set in the main `run_pipeline.sh` script or exported in your shell environment before running.
```bash
export OPENAI_API_KEY="your_openai_api_key_here"
```

## 3. Run the Script Directly
This command runs the segmentation script on a pre-existing panorama image. It's useful for quick tests. The paths provided are the internal paths within the container, which are mapped from your local folders.
```bash
# This command runs the service and executes the python script
docker-compose run --rm segmentation python segment_panorama.py \
    --panorama_path /app/data/indoor_livingroom/diffusion_img.png \
    --output_dir /app/output/indoor_livingroom_masks \
    --sam_checkpoint /app/checkpoints/sam_vit_h_4b8939.pth
```
* Note: The `--panorama_path` (`/app/data/...`) points to a file that must have been generated by the `dreamscene360_service` first. The `/app/data` volume is a read-only mount of the `dreamscene360_service/data` directory.

## 4. Run an Interactive Session
For debugging the Python script (`segment_panorama.py`), it's best to get an interactive shell inside the container.
```bash
docker-compose run --rm segmentation /bin/bash
```
